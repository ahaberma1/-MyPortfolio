# Personal portfolio

A Roblox-inspired personal portfolio with About Me, Experience, Projects, and Contact sections. The visual theme uses a block avatar, tilted square motifs, and profile cards. Content is based on Amber Haberman’s supplied résumé. Project illustrations are decorative rather than actual screenshots.

## Run

From `/workspace/-MyPortfolio`, run:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

No installation or build is required. CSS is in `style.css`, content is in `index.html`, and project dialogs are in `script.js`.

## Personalize

Update the bio, skills, experience, and project details in `index.html` and `script.js`. Add real project screenshots and project links when available. Email and GitHub links are already connected. Optional Google Fonts have system fallbacks. Independent portfolio; no official Roblox affiliation.
